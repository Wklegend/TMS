# مكتب وليد — نسخة تجريبية

نموذج تفاعلي لإدارة المهام والمشاريع والتدريب وتكليفات الموظفين والابتكار، بواجهة عربية (مع زر تبديل إلى الإنجليزية).

## التشغيل على GitHub Pages
1. ارفع الملف `index.html` إلى جذر المستودع.
2. من **Settings ← Pages** اختر: Source = Deploy from a branch، Branch = `main` / `(root)`، ثم Save.
3. بعد دقيقة يظهر الرابط بالشكل: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## ملاحظات النسخة المستقلة
- البيانات تُحفظ في متصفح الجهاز فقط (localStorage)، ولا تنتقل بين الأجهزة أو المستخدمين.
- المساعد الذكي، ورفع الملفات إلى Google Drive، وبوابة الموظفين تعمل في نسخة Claude فقط.
- لا يحتوي المستودع على أي بيانات حقيقية؛ استورد ملف Excel من داخل الموقع (المهام ← استيراد Excel).
- نزّل نسخة احتياطية من الإعدادات قبل مسح بيانات المتصفح.
