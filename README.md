## الملفات الرئيسية
- `index.html`: الصفحة التعريفية (الرئيسية) — منها تسجيل الدخول والاشتراك والفيديو التعريفي.
- `app.html`: المنصة نفسها، تُفتح بعد تسجيل الدخول.
- أول مرة: من «تسجيل الدخول» اضغط «أنا مدير المنصة: إنشاء حساب المدير». الموظفون يدخلون ببريدهم أو جوالهم، وكلمة المرور الافتراضية رقم الجوال.

# إدارة التدريب والجودة والابتكار (TQMS)

نموذج تفاعلي لإدارة المهام والمشاريع والتدريب وتكليفات الموظفين والابتكار، بواجهة عربية مع زر تبديل إلى الإنجليزية.

## التشغيل
افتح `index.html` في المتصفح، أو انشره على GitHub Pages.

## ربط ملف Google Sheets (قاعدة البيانات)
ملف قاعدة البيانات: «Tasks my» في Google Drive.
1. افتح الملف ← **Extensions ← Apps Script**.
2. احذف كل المحتوى، والصق محتوى `google-sheets/Code.gs` (الإصدار 2)، ثم **Save**.
3. اختر الدالة **setup** ← **Run**. تنشئ الجداول العلائقية والجداول المرجعية وقاموس البيانات، وتنقل أي بيانات من الإصدار السابق، وتطبع `TOKEN` في **Execution log**.
4. اختر الدالة **importTrackerAll** ← **Run**: تسحب كل مهام ورقة **All** من ملف Monthly Tasks Tracker، مع الموظفين والأقسام، دون تكرار.
5. اختر **installTrackerSync** ← **Run**: يسحب أي مهام جديدة تُضاف إلى ورقة All كل ساعة تلقائيًا.
6. **Deploy ← Manage deployments ← ✏️ Edit ← Version: New version ← Deploy** (إن كان منشورًا سابقًا)، أو **Deploy ← New deployment ← Web app** (Execute as: Me، Who has access: Anyone). انسخ رابط `/exec`.
7. في الموقع: **الإعدادات ← قاعدة البيانات**: الصق الرابط والرمز ← «اختبار الاتصال» ← «حفظ والاتصال».

الرمز السري يمنع غيرك من القراءة والكتابة عبر الرابط، فلا تشاركه.
